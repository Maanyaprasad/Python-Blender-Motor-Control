# Python + Blender Motor Control System

## Week 4 Project

This project is a Python-based desktop application developed to control the rotational speed of a NEMA 17 motor and pulley system modeled in Blender. The project focuses on creating a simple mechanical control interface using Python while integrating Blender-created 3D models into a dynamic rotation workflow.
The application uses Blender-created .glb models imported into a Python environment through the Ursina Engine. The system includes real-time rotation controls, UI interaction, and basic mechanical motion testing for shaft and pulley components.


## Planned Features
- Python-based desktop application
- Start and Stop button controls
- Speed control slider
- Dynamic pulley rotation workflow
- Initial motor shaft rotation workflow
- Real-time rotation speed adjustment
- Blender .glb model integration
- Pivot-based mechanical rotation testing
- Basic UI interaction system using Ursina
