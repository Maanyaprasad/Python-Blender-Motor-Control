# Python + Blender Motor Control System

## Week 4 Project

This project is a Python-based desktop application developed to control the rotational speed of a NEMA 17 motor and pulley system modeled in Blender. The application focuses on creating a simple mechanical control interface using Python while integrating Blender-created 3D models into a dynamic motor rotation workflow.


## Planned Features
- Python-based desktop UI
- Start and Stop controls
- Speed control slider
- Dynamic motor shaft rotation
- Dynamic pulley rotation
- Real-time rotation speed adjustment
- Blender model integration workflow


## Tools & Technologies Used
- Blender 5.1.0
- Python
- Tkinter
- Ursina Engine
- VS Code
