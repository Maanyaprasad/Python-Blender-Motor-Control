# Python + Blender Motor Control System

## Week 4 Project

This project is a Python-based application created for controlling the rotational speed of a NEMA 17 motor and pulley system designed in Blender.

## Features Planned
- Python-based desktop UI
- Start and Stop controls
- Dynamic motor rotation
- Dynamic pulley rotation
- Speed control slider
- Blender + Python integration workflow

## Tools Used
- Blender 5.1.0
- Python
- Tkinter
- Blender Python API (bpy)

## Current Progress
- Week 3 mechanical models completed
- Project structure initialized
- Blender integration workflow started
